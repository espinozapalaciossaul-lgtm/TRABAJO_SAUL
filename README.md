Algoritmos de Regresión en Python
Instrucciones para Visual Studio Code
1. Instalar dependencias
Abre la terminal en VS Code y ejecuta:

pip install -r requirements.txt
2. Ejecutar los programas
Predicción de costo de terreno:

python prediccion_costo_terreno.py
Predicción de ventas de empleado:

python prediccion_ventas_empleado.py
Archivos incluidos
prediccion_costo_terreno.py → Regresión lineal: Costo del terreno vs Área
prediccion_ventas_empleado.py → Regresión lineal: Ventas del empleado por meses
requirements.txt → Librerías necesarias
Qué hace cada programa
Carga datos de ejemplo (puedes cambiarlos por datos reales)
Entrena un modelo de Regresión Lineal con scikit-learn
Muestra la ecuación del modelo
Evalúa la calidad (MSE y R²)
Hace predicciones para nuevos valores
Genera un gráfico y lo guarda como imagen PNG
¡Puedes modificar los arrays de datos para usar tus propios valores!
